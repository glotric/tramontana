# Tramontana project

Tramontana is the portable, policy-governed operating layer for AI work. The repository currently contains the Phase 1 product and architecture foundation; it does not yet contain the full application implementation.

Read `AGENTS.md` and the documents under `docs/` before changing architecture. Keep model runtimes and specialist agents replaceable behind stable interfaces, and preserve Tramontana's canonical project/task state, permissions, context provenance, and execution record.
